# Exam Grader

> [English version](README_EN.md)

Система автоматического распознавания и проверки экзаменационных бланков. Загрузите отсканированные PDF-формы и файл с правильными ответами — получите готовый Excel-отчёт с оценками и встроенными превью ячеек.

## Как это работает

1. **Загрузка** — многостраничный PDF со сканами бланков и Excel-файл с правильными ответами.
2. **Выбор режима распознавания:**
   - **CLIP (локально)** — каждая ячейка распознаётся отдельно с помощью модели CLIP, работающей локально. API-ключ не нужен.
   - **OpenAI Vision API** — всё изображение страницы отправляется в gpt-5.2. Требуется API-ключ OpenAI.
3. **Выравнивание** — каждая страница выравнивается по шаблону с помощью SIFT и гомографии.
4. **Распознавание** — ответы извлекаются выбранным методом.
5. **Проверка** — распознанные ответы сравниваются с правильными, баллы начисляются по настраиваемым весам.
6. **Экспорт** — результаты сохраняются в Excel с баллами по каждому заданию, суммой и встроенными превью ячеек.

## Стек технологий

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Интерфейс | Streamlit | Веб-интерфейс для загрузки файлов и просмотра результатов |
| Обработка PDF | PyMuPDF (fitz) | Конвертация PDF в изображения высокого разрешения |
| Обработка изображений | OpenCV, scikit-image | Выравнивание, пороговая обработка, поиск контуров |
| Распознавание (локально) | CLIP (transformers, PyTorch) | Поклеточное распознавание рукописных цифр |
| Распознавание (облако) | OpenAI Vision API (опционально) | Распознавание всей страницы через GPT-4o |
| Работа с данными | pandas | Сравнение ответов и подсчёт баллов |
| Экспорт в Excel | xlsxwriter, openpyxl | Форматированный вывод со встроенными изображениями |

## Быстрый старт (Windows)

**Требования:** [Python 3.10+](https://www.python.org/downloads/) — при установке поставьте галочку «Add Python to PATH».

Дважды кликните на **`start.bat`** — скрипт автоматически создаст виртуальное окружение, установит все зависимости и откроет приложение в браузере.

### Портативная версия (без установки Python)

Запустите **`build_portable.bat`** — скрипт скачает портативный Python и установит все зависимости в папку `python/`. После этого `start.bat` будет использовать этот локальный Python — устанавливать Python в систему не нужно.

## Ручная установка

```bash
git clone <repository-url>
cd streamlit-exam-form-app

python -m venv .venv
.venv\Scripts\activate  # Windows

pip install -r requirements.txt
pip install -e .
```

Для включения режима OpenAI Vision API (опционально):

```bash
pip install -e ".[openai]"
```

## Использование

```bash
streamlit run app.py
```

1. Выберите режим распознавания: **CLIP (локально)** или **OpenAI Vision API**.
2. Если выбран OpenAI — введите API-ключ.
3. Введите номер варианта экзамена.
4. Загрузите отсканированный PDF-файл.
5. Загрузите Excel-файл с правильными ответами (столбец `Вариант` и столбцы `1`–`10`).
6. Нажмите **Распознать**.
7. Скачайте готовый Excel-файл с результатами.

## Формат файла с ответами

| Вариант | 1 | 2 | 3 | ... | 10 |
|---------|---|---|---|-----|----|
| 1 | 275 | 38 | 14 | ... | 3,5 |
| 2 | 100 | 42 | 7 | ... | 2,0 |

## Система оценивания

Баллы за каждое задание настраиваются в `exam_grader/config.py`:

- Задание 1: 0,5 балла
- Задания 2–9: 1,0 балл каждое
- Задание 10: 1,5 балла
- Максимум: 10,0 баллов

Задание считается выполненным, если оригинальный ответ **или** замена совпадает с правильным ответом.
